news.json    -> the NEWS list on the Play page (newest first)
servers.json -> the partner servers shown in the Servers page
Edit these files on GitHub and press Commit: the launcher reads them every time it opens. Only you can change them.

News images: put the picture in data/images/ and write its file name in "image" (for example "welcome.png").
You can also use a full link (https://...). Best size: 640x360 (16:9).
