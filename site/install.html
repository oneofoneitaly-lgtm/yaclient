YA CLIENT

Launcher for Windows 10 and 11. Free.

Download YA Client.exe

How to install

1

Download

Press the button above and save the file anywhere you like.

2

Open it

Double-click YA Client.exe. The first time, a short setup asks for your account, mods and memory.

3

Press Launch Game

It downloads Java, Minecraft 1.8.9 and Forge by itself. The first start takes a few minutes.

4

Play

Press Right Shift in game for the mod menu. The launcher updates itself from now on.

Windows may show "Windows protected your PC" because the launcher is new and unsigned. Click More info, then Run anyway.

Requirements

System

Windows 10 or 11, 64-bit.

Memory

4 GB of RAM free is recommended.

Account

Microsoft account or offline nickname.
